# 7.5.3. Diagrama de Componentes (C3)

## Descripción de componentes

| Componente | Módulo | Archivo |
|---|---|---|
| **M1 Auth Router** | M1 | `src/modules/auth/router.py` |
| **M1 Session Store** | M1 | `src/modules/auth/redis_store.py` |
| **M2/M3 Queue Router** | M2, M3 | `src/modules/queues/router.py` |
| **M3 WebSocket Manager** | M3 | `src/modules/queues/manager.py` |
| **M3 Inactivity Worker** | M3 | `src/modules/queues/worker.py` |
| **M4 Notifications Consumer** | M4 | `src/modules/notifications/consumer.py` |
| **M5 Tracking Consumer** | M5 | `src/modules/tracking/consumer.py` |
| **M7 Config Proxy (Cache-Aside)** | M7 | `src/modules/config/router.py` |

> M6 (Reasignación) no tiene implementación aún — solo `__init__.py`. Su lógica está diseñada en `ReasignacionBase` / `ReasignacionFIFO` (ver [11.3](../../../11/11.3/11.3.md)).
