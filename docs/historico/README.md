# Archivo histórico

Este directorio conserva la documentación y los prototipos del trabajo previo de
ComedorUNI. Su contenido se reorganizó aquí para separar el archivo académico de
los entregables actuales de SW707.

- Los capítulos numerados y actividades de semanas anteriores son evidencia
  histórica; algunas decisiones, rutas o afirmaciones pueden no coincidir con el
  código actual.
- Para el estado vigente del sistema, consulta la [documentación SW707](../README.md)
  y el [README del repositorio](../../README.md).
- Los recursos compartidos actuales están en `resources/`; las referencias
  relativas de imágenes del archivo histórico se conservan cuando apuntan a ellos.
