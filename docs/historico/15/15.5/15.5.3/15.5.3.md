# 15.5.3. Componentes

Vistas de componentes del workspace consolidado definido en [15.5.1](../15.5.1/15.5.1.md). Los renders por módulo (Nivel 3) están en [7.1](../../../7/7.1/7.1.md), [7.2](../../../7/7.2/7.2.md) y [7.3](../../../7/7.3/7.3.md).

---

## Vistas de componentes (Structurizr DSL)

```structurizr
# Pertenecen al workspace consolidado de 15.5.1
component api "Componentes_API" {
    include *
    autolayout lr
}
component workerReasign "Componentes_M6" {
    include *
    autolayout lr
}
component consumers "Componentes_M4_M5" {
    include *
    autolayout lr
}
```

---

## Descripción de componentes por módulo

| Módulo | Componentes (en el contenedor) | Responsabilidad clave | Render |
|---|---|---|---|
| M1 – Autenticación | auth.router, Servicio de Autenticación, Scraping, Biometría, Gestor de Sesiones | Identidad multifactor + sesión con TTL | [7.1](../../../7/7.1/7.1.md) |
| M2 – Colas | queue.router, Validador de Restricciones, Control de Capacidad, Gestor FIFO | Encolado FIFO con cupo atómico | [7.2](../../../7/7.2/7.2.md) |
| M3 – Turnos | Generador de Turno, Gestor de Estado de Turno, Auditoría de Turnos | Máquina de estados ACID + auditoría | [7.2](../../../7/7.2/7.2.md) |
| M4 – Notificaciones | Consumer M4, Registro de Notificaciones | Despacho push + historial auditable | [7.1](../../../7/7.1/7.1.md) |
| M5 – Seguimiento | Servicio de Seguimiento, RealTime Channel | Estado/posición + tiempo real (WebSocket) | [7.1](../../../7/7.1/7.1.md) |
| M6 – Reasignación | consumer/handler, reassignment.service | Reasignación idempotente FIFO con SKIP LOCKED | [7.3](../../../7/7.3/7.3.md) |
| M7 – Configuración | config.router, config.service, Proxy de caché | Validación + Cache-Aside + invalidación | [7.3](../../../7/7.3/7.3.md) |

> Los componentes de M1, M2, M3, M5 y M7 residen en el contenedor `API Backend` (monolito); los de M6 y M4/M5 residen en sus contenedores worker/consumer respectivos. La vista `Componentes_API` muestra el interior del monolito; `Componentes_M6` y `Componentes_M4_M5`, el de los procesos separados.
