## Descripción de los Módulos
**M1 – Módulo de Autenticación**:

El módulo de autenticación es el encargado de gestionar el acceso de los usuarios al sistema, garantizando que únicamente estudiantes válidos puedan utilizar la plataforma. Para ello, se integra con un servicio externo de autenticación como Google Auth, el cual permite verificar la identidad del usuario a través de sus credenciales institucionales.

Este módulo no solo valida el correo del estudiante, sino que también asegura que pertenezca al dominio institucional correspondiente (por ejemplo, @uni.pe), filtrando accesos no autorizados. Además, se complementa con la verificación de la condición de estudiante activo mediante consultas a servicios institucionales.

Asimismo, se encarga de la gestión de sesiones, asegurando que cada usuario tenga una sesión única, segura e intransferible dentro del sistema. Este módulo actúa como punto de entrada al sistema, permitiendo o denegando el acceso a los demás módulos según el resultado de la autenticación.

**M2 – Módulo de Gestión de Colas**:

El módulo de gestión de colas es responsable de administrar la estructura general de las colas virtuales del sistema. Su función principal es organizar a los estudiantes en un orden de atención sin necesidad de presencia física, respetando las reglas de negocio definidas, como el orden de llegada (FIFO) y la capacidad limitada de cada cola.

Este módulo define y mantiene las colas correspondientes a cada tipo de servicio (por ejemplo, almuerzo o cena), estableciendo la cantidad máxima de estudiantes que pueden ser atendidos en cada periodo. Además, organiza estas colas en bloques de tiempo, lo que permite distribuir la atención de manera más eficiente y evitar la saturación en determinados horarios.

También se encarga de gestionar el estado de las colas en tiempo real, controlando la disponibilidad de cupos y proporcionando información actualizada a otros módulos, como el de turnos o el de seguimiento.

**M3 – Módulo de Gestión de Turnos**:

El módulo de gestión de turnos se encarga de la creación, asignación y control de los turnos individuales de los estudiantes. A diferencia del módulo de colas, que trabaja a nivel estructural, este módulo opera a nivel individual, gestionando cada turno como una entidad propia dentro del sistema.

Entre sus funciones principales se encuentra la generación de turnos a partir de la disponibilidad de las colas, asignando a cada estudiante un horario específico dentro de un bloque de tiempo. Además, controla el ciclo de vida del turno, incluyendo estados como asignado, activo, confirmado o perdido.

Este módulo también gestiona la confirmación de asistencia por parte del estudiante, verificando que se realice dentro del tiempo establecido. En caso contrario, se encarga de marcar el turno como no confirmado y proceder con su liberación.

**M4 – Módulo de Notificaciones**:

El módulo de notificaciones tiene como objetivo mantener informado al estudiante sobre los eventos relevantes relacionados con su turno dentro del sistema. Este módulo actúa como un canal de comunicación entre el sistema y el usuario, mejorando la experiencia y reduciendo la incertidumbre durante el proceso.

Entre sus funciones principales se encuentra el envío de notificaciones cuando se asigna un turno, cuando el turno está próximo a iniciar o cuando ya se encuentra activo. Asimismo, puede notificar eventos como la pérdida de un turno por falta de confirmación o la reasignación de cupos.

Este módulo trabaja en coordinación con el módulo de gestión de turnos para activarse en momentos clave del ciclo de vida del turno.

**M5 – Módulo de Seguimiento**:

El módulo de seguimiento permite al estudiante consultar en tiempo real el estado de su turno y su posición dentro de la cola virtual. Su objetivo es brindar visibilidad y transparencia sobre el proceso, reduciendo la incertidumbre y mejorando la experiencia del usuario.

Este módulo obtiene información tanto del módulo de gestión de colas como del módulo de gestión de turnos, integrando estos datos para mostrar al estudiante información relevante, como el turno asignado, el tiempo estimado de atención y el estado actual del proceso.

Además, puede ofrecer un historial básico de eventos relacionados con el turno, permitiendo al usuario conocer acciones como la asignación, confirmación o pérdida del turno. En esencia, este módulo actúa como la interfaz de consulta del sistema.

**M6 – Módulo de Reasignación**:

El módulo de reasignación se encarga de gestionar la redistribución automática de los turnos que han sido liberados, principalmente debido a la falta de confirmación por parte de los estudiantes.

Cuando un turno es marcado como no confirmado, este módulo detecta la disponibilidad del cupo y procede a asignarlo a otro estudiante que se encuentre en espera dentro de la cola virtual. Este proceso se realiza respetando el orden de prioridad establecido (FIFO), garantizando equidad en la asignación.

Además, este módulo trabaja de manera coordinada con el módulo de gestión de colas y el módulo de turnos, asegurando que la información se mantenga consistente y actualizada. Su objetivo principal es maximizar el aprovechamiento de los cupos disponibles y evitar pérdidas en la capacidad del servicio.

**M7 – Módulo de Configuración**:

El módulo de configuración está orientado al uso por parte del administrador del sistema, permitiendo definir y ajustar los parámetros necesarios para el correcto funcionamiento de la plataforma.

Entre sus funciones se encuentra la configuración de los horarios de atención, la definición de la capacidad de las colas, la duración de los bloques de tiempo y el tiempo máximo de confirmación de asistencia. Estas configuraciones influyen directamente en el comportamiento de otros módulos, como colas y turnos.

Además, este módulo permite adaptar el sistema a diferentes condiciones operativas, como cambios en la demanda o en la disponibilidad del servicio. De esta manera, proporciona flexibilidad y control sobre el funcionamiento general del sistema.
