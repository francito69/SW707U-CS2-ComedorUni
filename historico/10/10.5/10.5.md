# 10.5. Diccionario de Datos Consolidado

Reúne en una sola referencia todos los atributos de todas las tablas de PostgreSQL y las estructuras de Redis del sistema. Las tablas están ordenadas por módulo propietario.

---

## PostgreSQL — Tablas

### `estudiantes` — M1 · Autenticación

| Atributo | Tipo | Longitud / Formato | Obligatorio | Dominio / Restricciones | Descripción funcional |
|---|---|---|---|---|---|
| `id` | SERIAL | Entero autoincremental | Sí | PK | Identificador interno del estudiante |
| `codigo` | VARCHAR | 20 caracteres | Sí | UNIQUE, no nulo | Código institucional UNI (formato `20XXXXXXL`) |
| `nombres` | VARCHAR | 255 caracteres | Sí | No nulo | Uno o dos nombres según registro en Intranet UNI |
| `apellido_paterno` | VARCHAR | 255 caracteres | Sí | No nulo | Apellido paterno |
| `apellido_materno` | VARCHAR | 255 caracteres | No | Puede ser nulo | Apellido materno |
| `email` | VARCHAR | 255 caracteres | No | UNIQUE, formato email | Correo institucional `@uni.pe` |
| `push_token` | VARCHAR | 255 caracteres | No | Cadena opaca del proveedor | Token del dispositivo para notificaciones push (M4) |
| `created_at` | TIMESTAMP | `YYYY-MM-DD HH:MM:SS` | Sí | DEFAULT `NOW()` | Fecha y hora de primer registro en el sistema |

> La foto del estudiante **no se persiste**: se obtiene de ORCE en cada login y se almacena temporalmente en la sesión Redis.

### `turnos_config` — M7 · Configuración (plantilla de servicios)

| Atributo | Tipo | Longitud / Formato | Obligatorio | Dominio / Restricciones | Descripción funcional |
|---|---|---|---|---|---|
| `id` | SERIAL | Entero autoincremental | Sí | PK | Identificador de la plantilla |
| `tipo` | VARCHAR | 20 caracteres | Sí | UNIQUE; valores: `ALMUERZO`, `CENA`, `PRUEBA` | Nombre del tipo de servicio del comedor |
| `hora_apertura` | TIME | `HH:MM:SS` | Sí | No nulo | Hora predeterminada de apertura de la cola |
| `hora_inicio` | TIME | `HH:MM:SS` | Sí | No nulo | Hora predeterminada de inicio de atención |
| `hora_cierre` | TIME | `HH:MM:SS` | Sí | No nulo | Hora predeterminada de cierre del servicio |
| `raciones_max` | INTEGER | Entero positivo | Sí | DEFAULT `5000` | Capacidad predeterminada; determina el tamaño de grupo `⌈raciones_max / 10⌉` |
| `activo` | BOOLEAN | `true` / `false` | Sí | DEFAULT `TRUE` | Si es `false`, M2 no permite encolamiento |

### `turno_dia` — M2 · Gestión de Colas (instancia diaria)

| Atributo | Tipo | Longitud / Formato | Obligatorio | Dominio / Restricciones | Descripción funcional |
|---|---|---|---|---|---|
| `id` | SERIAL | Entero autoincremental | Sí | PK | Identificador de la instancia del servicio del día |
| `config_id` | INTEGER | Entero | Sí | FK → `turnos_config.id`, no nulo | Plantilla de la que hereda horarios y capacidad |
| `fecha` | DATE | `YYYY-MM-DD` | Sí | DEFAULT `CURRENT_DATE`; UNIQUE con `config_id` | Fecha del servicio; garantiza un único ALMUERZO y una única CENA por día |
| `raciones_max` | INTEGER | Entero positivo | No | Sobreescribe `turnos_config.raciones_max` si se especifica | Capacidad ajustada para este día específico |
| `hora_apertura` | TIME | `HH:MM:SS` | No | Sobreescribe `turnos_config.hora_apertura` si se especifica | Hora de apertura de cola específica para este día |
| `hora_cierre` | TIME | `HH:MM:SS` | No | Sobreescribe `turnos_config.hora_cierre` si se especifica | Hora de cierre específica para este día |
| `abierto` | BOOLEAN | `true` / `false` | Sí | DEFAULT `TRUE` | Permite cerrar manualmente el servicio sin eliminar el registro |
| `created_at` | TIMESTAMP | `YYYY-MM-DD HH:MM:SS` | Sí | DEFAULT `NOW()` | Fecha y hora de creación del registro |

### `turnos` — M3 · Gestión de Turnos

| Atributo | Tipo | Longitud / Formato | Obligatorio | Dominio / Restricciones | Descripción funcional |
|---|---|---|---|---|---|
| `id` | SERIAL | Entero autoincremental | Sí | PK | Identificador único del turno |
| `estudiante_id` | INTEGER | Entero | Sí | FK → `estudiantes.id`, no nulo | Estudiante al que pertenece el turno |
| `turno_dia_id` | INTEGER | Entero | Sí | FK → `turno_dia.id`, no nulo | Servicio del día al que corresponde el turno |
| `numero_turno` | INTEGER | Entero positivo | Sí | No nulo; `MAX + 1` por `turno_dia_id` al momento del registro | Posición de llegada; define el orden FIFO |
| `estado` | VARCHAR | 20 caracteres | Sí | CHECK: `ESPERANDO`, `LLAMADO`, `ATENDIDO`, `CANCELADO`; DEFAULT `ESPERANDO` | Estado actual en el ciclo de vida del turno |
| `ingresado_at` | TIMESTAMP | `YYYY-MM-DD HH:MM:SS` | Sí | DEFAULT `NOW()` | Momento de ingreso a la cola |
| `llamado_at` | TIMESTAMP | `YYYY-MM-DD HH:MM:SS` | No | Nulo hasta que M3 llame al grupo | Momento en que el sistema llamó al grupo del turno |
| `confirmado_at` | TIMESTAMP | `YYYY-MM-DD HH:MM:SS` | No | Nulo si no confirmó | Momento en que el estudiante confirmó su presencia |
| `cancelado_at` | TIMESTAMP | `YYYY-MM-DD HH:MM:SS` | No | Nulo si no fue cancelado | Momento de cancelación (por inactividad o por el estudiante) |
| `ultimo_ping` | TIMESTAMP | `YYYY-MM-DD HH:MM:SS` | Sí | DEFAULT `NOW()`; actualizado con cada heartbeat | Última señal de vida; si lleva > 3 minutos sin actualizarse en estado `LLAMADO`, el worker cancela el turno |

## Redis — Estructuras clave/valor

### `session:{sid}` — M1 · Autenticación

| Campo | Tipo | Formato | Obligatorio | Dominio | Descripción funcional |
|---|---|---|---|---|---|
| clave | String | `session:{sid}` donde `sid` es UUID v4 | Sí | — | Identifica la sesión activa del estudiante |
| `codigo` | String | Alfanumérico, máx 20 | Sí | Igual a `estudiantes.codigo` | Código institucional del estudiante |
| `email` | String | Formato email | No | Igual a `estudiantes.email` | Correo cacheado en sesión |
| `nombre` | String | Texto libre | Sí | Nombre completo | Nombre mostrado en la interfaz sin consultar PostgreSQL |
| `creditos` | Integer | Entero positivo | Sí | Obtenido del scraping de Intranet al login | Créditos llevados; cacheados para no repetir el scraping |
| `foto_base64` | String | Cadena Base64 de imagen JPG/PNG | No | Obtenida de ORCE al login | Foto vigente del estudiante para la verificación biométrica; no se persiste en BD |
| TTL | Integer | Segundos | Sí | 28 800 s (8 horas) | Tiempo de vida de la sesión; al vencer el estudiante debe autenticarse de nuevo |

---

### `user_session:{codigo}` — M1 · Autenticación

| Campo | Tipo | Formato | Obligatorio | Dominio | Descripción funcional |
|---|---|---|---|---|---|
| clave | String | `user_session:{codigo}` | Sí | `codigo` es el código institucional | Permite localizar el `sid` activo de un estudiante |
| valor | String | UUID v4 | Sí | Igual al `sid` de la sesión activa | Usado en el login para invalidar una sesión previa (sesión única) |
| TTL | Integer | Segundos | Sí | 28 800 s (8 horas), sincronizado con `session:{sid}` | Se elimina junto con la sesión en el logout |

---

### `turnos_config:cache` — M7 · Configuración

| Campo | Tipo | Formato | Obligatorio | Dominio | Descripción funcional |
|---|---|---|---|---|---|
| clave | String | `turnos_config:cache` | Sí | Fija | Copia en caché de las filas activas de `turnos_config` |
| valor | String JSON | Array de objetos con todos los campos de `turnos_config` | Sí | Ver tabla `turnos_config` | Leído por M2 y M7 sin consultar PostgreSQL (*cache-aside*) |
| TTL | Integer | Segundos | Sí | 180 s | Expiración automática como red de seguridad; invalidación dirigida con `DEL` al modificar la configuración |
