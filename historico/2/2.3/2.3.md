# 2.3. Glosario de Términos

| Término                       | Definición                                                                                                                                                                    |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Turno                         | Asignación de un intervalo de tiempo específico otorgado a un estudiante para ser atendido en el servicio de comedor, previa confirmación de asistencia.                      |
| Cola virtual                  | Mecanismo digital que organiza a los estudiantes en un orden de atención sin necesidad de presencia física, en función de la disponibilidad de cupos y el orden de solicitud. |
| Cupo                          | Unidad disponible dentro de una cola virtual que representa la capacidad máxima de atención en un intervalo de tiempo determinado.                                            |
| Estudiante activo             | Usuario que se encuentra matriculado en el periodo académico vigente y validado mediante credenciales institucionales.                                                        |
| Solicitud de turno            | Acción mediante la cual un estudiante registra su intención de obtener un turno para el servicio de comedor a través del sistema.                                             |
| Asignación de turno           | Proceso mediante el cual el sistema otorga un turno a un estudiante según la disponibilidad de cupos y las reglas de negocio.                                                 |
| Confirmación de asistencia    | Acción realizada por el estudiante para validar que hará uso del turno asignado dentro del tiempo establecido.                                                                |
| Tiempo límite de confirmación | Intervalo máximo definido por el sistema para que el estudiante confirme su asistencia antes de que el turno sea liberado.                                                    |
| Reasignación de turno         | Proceso mediante el cual un cupo liberado por inasistencia es asignado a otro estudiante en espera.                                                                           |
| Disponibilidad de cupos       | Estado que indica si existen espacios disponibles dentro de las colas virtuales para la asignación de nuevos turnos.                                                          |
| Validación de usuario         | Proceso de verificación de identidad y condición académica del estudiante mediante credenciales institucionales y servicios externos.                                         |
| Notificación                  | Mensaje enviado por el sistema al estudiante para informarle sobre el estado de su turno, como asignación o inicio.                                                           |
| Orden de llegada (FIFO)       | Regla de asignación en la que los turnos se otorgan según el orden en que los estudiantes realizan su solicitud.                                                              |
| Turno no confirmado           | Estado en el cual un turno asignado es liberado automáticamente debido a la falta de confirmación dentro del tiempo establecido.                                              |
| Bloque de tiempo              | Intervalo definido dentro de la cola virtual que agrupa turnos con un horario de inicio y duración específicos.                                                               |
| Sistema de turnos             | Plataforma encargada de gestionar la solicitud, asignación, confirmación y organización de turnos dentro de la cola virtual del comedor.                                      |
