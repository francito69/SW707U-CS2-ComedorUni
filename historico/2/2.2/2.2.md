# 2.2. Descripción de Actividades

| Nº  | Actividad                              | Descripción                                                                                             | Responsable | Entradas                               | Salidas                         | Reglas de negocio                                | Sistema implicado                     |
| --- | -------------------------------------- | ------------------------------------------------------------------------------------------------------- | ----------- | -------------------------------------- | ------------------------------- | ------------------------------------------------ | ------------------------------------- |
| A1  | Ingresar credenciales institucionales  | El estudiante ingresa sus credenciales (@uni.pe) para acceder al sistema y poder solicitar un turno.    | Estudiante  | Credenciales del estudiante            | Solicitud de autenticación      | RN01: Acceso solo para estudiantes activos       | Sistema de Turnos                     |
| A2  | Validar condición de estudiante activo | El sistema verifica que el usuario sea un estudiante activo consultando la información institucional.   | Sistema     | Credenciales del estudiante            | Validación (válido / no válido) | RN01: Validación de estudiante activo            | Sistema de Turnos / API institucional |
| A3  | Solicitar turno                        | El estudiante realiza la solicitud de un turno dentro de los horarios habilitados.                      | Estudiante  | Solicitud de turno                     | Solicitud registrada            | RN04, RN05: Restricción de un turno por servicio | Sistema de Turnos                     |
| A4  | Verificar disponibilidad de cupos      | El sistema verifica si existen cupos disponibles en las colas virtuales.                                | Sistema     | Solicitud de turno, capacidad de colas | Disponibilidad de cupos         | RN08: Capacidad limitada de colas                | Sistema de Turnos                     |
| A5  | Asignar cola virtual                   | El sistema asigna al estudiante a una cola virtual según disponibilidad y orden de llegada.             | Sistema     | Cupos disponibles, lista de colas      | Cola asignada                   | RN06: Asignación por orden de llegada (FIFO)     | Sistema de Turnos                     |
| A6  | Generar turno                          | El sistema crea el turno con la hora correspondiente según la cola asignada.                            | Sistema     | Cola asignada                          | Turno generado                  | RN09: Organización por bloques de tiempo         | Sistema de Turnos                     |
| A7  | Notificar turno al estudiante          | El sistema informa al estudiante el turno asignado y su horario correspondiente.                        | Sistema     | Turno generado                         | Notificación enviada            | RN09: Información del turno                      | Sistema de Turnos                     |
| A8  | Notificar inicio de turno              | El sistema envía una notificación indicando que el turno del estudiante se encuentra activo.            | Sistema     | Hora de inicio del turno               | Notificación de inicio          | RN11: Obligación de confirmar asistencia         | Sistema de Turnos                     |
| A9  | Confirmar asistencia                   | El estudiante confirma su asistencia dentro del tiempo máximo definido por el sistema.                  | Estudiante  | Notificación de turno                  | Confirmación de asistencia      | RN12: Tiempo máximo de confirmación              | Sistema de Turnos                     |
| A10 | Liberar cupo                           | El sistema libera el cupo cuando el estudiante no confirma su asistencia dentro del tiempo establecido. | Sistema     | Turno no confirmado                    | Cupo disponible                 | RN13: Pérdida de turno por inactividad           | Sistema de Turnos                     |
| A11 | Reasignar turno                        | El sistema asigna el cupo liberado a otro estudiante en espera dentro de la cola virtual.               | Sistema     | Cupo liberado                          | Nuevo turno asignado            | RN14, RN15: Reasignación de turnos               | Sistema de Turnos                     |
