## Decisiones transversales destacadas

Estas decisiones aparecen en varios módulos y forman el esqueleto arquitectónico del sistema:

| Decisión | ADRs relacionados |
|---|---|
| **Monolito FastAPI modular** (no microservicios) | ADR-M1-013, ADR-COL-006, ADR-TUR-006, ADR-M4-006, ADR-M5-005 |
| **PostgreSQL como fuente de verdad** (no Redis para estado) | ADR-COL-001, ADR-M6-003, ADR-M7-007 |
| **Redis solo para sesiones y caché** (no como BD principal) | ADR-M1-002, ADR-M7-008 |
| **RabbitMQ para desacoplamiento inter-módulo** | ADR-COL-007, ADR-TUR-005, ADR-M4-002, ADR-M5-002 |
| **WebSocket para tiempo real in-process** | ADR-COL-007, ADR-TUR-004, ADR-TUR-008 |
| **`FOR UPDATE SKIP LOCKED` para concurrencia** | ADR-COL-004, ADR-M6-005 |
| **Expo Push Notifications** (no SSE, no FCM directo) | ADR-M4-001 |
| **Datos efímeros en Redis, no en PostgreSQL** | ADR-M1-003, ADR-M1-006 |
