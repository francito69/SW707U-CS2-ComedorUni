# 3.1.5. Listado Consolidado

## Requerimientos Funcionales Consolidados

---

## M1 · Autenticación
**Responsable:** Yazid Elio Fernandez Dueñas

| ID        | Requerimiento | Actor |
|-----------|---------------|-------|
| RF-M1-01  | El sistema debe permitir que el estudiante ingrese sus credenciales institucionales (@uni.pe) para acceder. | Estudiante |
| RF-M1-02  | El sistema debe validar las credenciales del estudiante a través de un servicio externo de autenticación. | Sistema |

| RF-M1-04  | El sistema debe rechazar el acceso si el estudiante no es activo o sus credenciales son inválidas. | Sistema |

| RF-M1-06  | El sistema debe registrar el evento de autenticación con fecha, hora y resultado para auditoría. | Sistema |
| RF-M1-07  | El sistema debe permitir que el estudiante cierre su sesión de manera segura. | Estudiante |

## Casos de Uso Detallados

---

### M1 · Autenticación

**CU-M1-01: Autenticación de Estudiante**
- **Actor:** Estudiante
- **Descripción:** El estudiante inicia sesión en el sistema con credenciales institucionales.
- **Flujo principal:** Ingresa credenciales → Sistema valida → Verifica estudiante activo → Crea sesión → Acceso otorgado

**CU-M1-02: Cierre Seguro de Sesión**
- **Actor:** Estudiante
- **Descripción:** El estudiante cierra su sesión de manera segura.
- **Flujo principal:** Estudiante solicita cierre → Sistema invalida token → Limpia datos locales → Redirige a autenticación

---

### M2 · Gestión de Colas

**CU-M2-01: Registrar Estudiante en Cola**
- **Actor:** Estudiante
- **Descripción:** Permite al estudiante entrar a la cola virtual al solicitar un turno.
- **Flujo principal:** Solicita turno → Verifica disponibilidad → Valida sin turno activo → Registra en cola → Asigna posición FIFO

**CU-M2-02: Retirar Estudiante de Cola**
- **Actor:** Estudiante / Sistema
- **Descripción:** Permite retirar al estudiante de la cola virtual.
- **Flujo principal:** Identifica estudiante → Elimina de cola → Actualiza estado → Libera cupo

---

### M3 · Gestión de Turnos

**CU-M3-01: Generar Turno**
- **Actor:** Estudiante
- **Descripción:** El sistema genera un turno a partir del registro en cola.
- **Flujo principal:** Cola registrada → Valida sin turno activo → Genera turno único → Asigna bloque horario → Notifica estudiante

**CU-M3-02: Confirmar Asistencia**
- **Actor:** Estudiante
- **Descripción:** El estudiante confirma su asistencia dentro del tiempo límite.
- **Flujo principal:** Turno activo → Estudiante confirma → Sistema registra confirmación → Actualiza estado turno

**CU-M3-03: Liberar Turno por Inasistencia**
- **Actor:** Sistema
- **Descripción:** El sistema libera automáticamente un turno al expirar el tiempo de confirmación.
- **Flujo principal:** Tiempo de confirmación expira → Marca como no confirmado → Libera cupo → Inicia reasignación

---

### M4 · Notificaciones

**CU-M4-01: Notificar Asignación de Turno**
- **Actor:** Sistema
- **Descripción:** Notifica al estudiante cuando se le asigna un turno.
- **Flujo principal:** Turno asignado → Prepara notificación → Envía por canales → Registra en historial

**CU-M4-02: Notificar Confirmación Requerida**
- **Actor:** Sistema
- **Descripción:** Notifica al estudiante que debe confirmar su asistencia.
- **Flujo principal:** Turno activado → Envía notificación de confirmación → Especifica plazo → Registra envío

**CU-M4-03: Configurar Preferencias de Notificación**
- **Actor:** Estudiante
- **Descripción:** El estudiante configura cómo desea recibir notificaciones.
- **Flujo principal:** Accede a preferencias → Selecciona canales → Elige tipos de eventos → Guarda configuración

---

### M5 · Seguimiento

**CU-M5-01: Consultar Estado del Turno**
- **Actor:** Estudiante
- **Descripción:** El estudiante verifica el estado actual de su turno.
- **Flujo principal:** Accede a estado → Sistema obtiene turno activo → Muestra horario y bloque → Registra consulta

**CU-M5-02: Consultar Posición en Cola**
- **Actor:** Estudiante
- **Descripción:** El estudiante ve su posición en la cola si está en espera.
- **Flujo principal:** Accede a cola → Sistema calcula posición → Muestra número y estimado → Registra consulta

**CU-M5-03: Consultar Historial de Turnos**
- **Actor:** Estudiante
- **Descripción:** El estudiante revisa todos sus turnos previos.
- **Flujo principal:** Accede a historial → Sistema obtiene turnos pasados → Muestra con detalles → Registra consulta

**CU-M5-04: Registrar Evento para Auditoría**
- **Actor:** Sistema
- **Descripción:** El sistema registra automáticamente los eventos relevantes.
- **Flujo principal:** Evento ocurre → Captura timestamp, actor, estudiante → Almacena en historial de auditoría

---

### M6 · Reasignación de Turnos

**CU-M6-01: Liberar Turno por Inasistencia**
- **Actor:** Sistema
- **Descripción:** El sistema libera el turno cuando expira confirmación.
- **Flujo principal:** Tiempo expira → Marca no confirmado → Libera cupo → Inicia reasignación automática

**CU-M6-02: Reasignar Turno a Estudiante en Espera**
- **Actor:** Sistema
- **Descripción:** El sistema reasigna el cupo liberado al próximo en la cola.
- **Flujo principal:** Cupo liberado → Identifica siguiente en espera → Valida elegibilidad → Asigna turno → Notifica

---

### M7 · Configuración del Sistema

**CU-M7-01: Configurar Horarios y Bloques**
- **Actor:** Administrador
- **Descripción:** Define horarios y bloques de tiempo para cada servicio.
- **Flujo principal:** Accede configuración → Define horarios (almuerzo/cena) → Establece bloques → Valida conflictos → Guarda

**CU-M7-02: Configurar Capacidad por Turno**
- **Actor:** Administrador
- **Descripción:** Define la capacidad máxima de estudiantes por turno.
- **Flujo principal:** Ingresa capacidad → Valida viabilidad → Guarda configuración → Aplica a nuevas solicitudes

**CU-M7-03: Configurar Períodos de Solicitud**
- **Actor:** Administrador
- **Descripción:** Define cuándo los estudiantes pueden solicitar turnos.
- **Flujo principal:** Define fechas y horarios → Valida período → Guarda → Sistema habilita/deshabilita solicitudes

**CU-M7-04: Configurar Tiempo de Confirmación**
- **Actor:** Administrador
- **Descripción:** Define el tiempo máximo para confirmar asistencia.
- **Flujo principal:** Ingresa tiempo en minutos → Valida coherencia → Guarda → Aplica a nuevos turnos
