# 3.1.2. Módulo 2 / Integrante 2

**Módulos asignados**
- M2: Gestión de colas
- M3: Gestión de turnos

## Módulo 2: Gestión de colas

El módulo de gestión de colas se encarga de organizar a los estudiantes dentro de una cola virtual cuando solicitan un turno para el comedor. Su función principal es mantener el orden en el que los estudiantes van ingresando, respetando el principio de “primero en llegar, primero en ser atendido” (FIFO).

Cuando un estudiante solicita un turno, este módulo verifica si todavía hay cupos disponibles y, en caso de que sí, lo registra dentro de la cola asignándole una posición. A partir de ese momento, el estudiante forma parte de la cola y su turno dependerá de su ubicación en ella.

Además, el módulo controla en todo momento la cantidad de cupos disponibles, evitando que se exceda la capacidad definida para cada servicio. También se encarga de mantener la cola actualizada, ya que esta información es necesaria para que el módulo de gestión de turnos pueda asignar los horarios correspondientes.

Es importante mencionar que este módulo no se encarga de mostrar la información al usuario, ni de configurar parámetros como horarios o capacidad, ni de reasignar turnos. Su responsabilidad está enfocada únicamente en mantener el orden y la disponibilidad dentro de la cola virtual.

| ID   | Requisito Funcional                                                                                                                        | Actor(es)  |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------ | ---------- |
| RF01 | El sistema debe permitir registrar a un estudiante en una cola virtual cuando solicite un turno para el servicio de comedor.               | Estudiante |
| RF02 | El sistema debe verificar la disponibilidad de cupos antes de permitir el ingreso de un estudiante a la cola.                              | Sistema    |
| RF03 | El sistema debe validar que el estudiante no tenga un turno activo antes de registrarlo en la cola.                                        | Sistema    |
| RF04 | El sistema debe asignar y mantener automáticamente la posición de los estudiantes dentro de la cola respetando el orden de llegada (FIFO). | Sistema    |
| RF05 | El sistema debe controlar que no se exceda la capacidad máxima de la cola virtual.                                                         | Sistema    |
| RF06 | El sistema debe actualizar la disponibilidad de cupos cuando un estudiante ingresa a la cola o cuando se libera un cupo.                   | Sistema    |


## Casos de Uso
### CU01: Registrar estudiante en cola

| Campo       | Detalle                                                                               |
| ----------- | ------------------------------------------------------------------------------------- |
| Nombre      | Registrar estudiante en cola                                                          |
| Actor       | Estudiante                                                                            |
| Descripción | Permite al estudiante ingresar a una cola virtual disponible para solicitar un turno. |

<br>

**Flujo principal**
1. El estudiante solicita un turno.
2. El sistema verifica la disponibilidad de cupos.
3. El sistema valida que el estudiante no tenga un turno activo.
4. El sistema registra al estudiante en la cola.
5. El sistema asigna automáticamente su posición según el orden de llegada (FIFO).

**Flujos alternativos**
1. No hay cupos disponibles → se rechaza la solicitud.
2. El estudiante ya tiene un turno activo → no se permite el registro.

**Postcondiciones**
1. El estudiante queda registrado en la cola.
2. La cola mantiene su orden actualizado.

**Excepciones**
1. Error en la verificación de cupos.
2. Fallo en el registro del estudiante.


### CU02: Retirar estudiante de la cola
| Campo       | Detalle                                                                                                   |
| ----------- | --------------------------------------------------------------------------------------------------------- |
| Nombre      | Retirar estudiante de la cola                                                                             |
| Actor       | Estudiante / Sistema                                                                                      |
| Descripción | Permite retirar a un estudiante de la cola virtual, ya sea por decisión propia o por eventos del sistema. |

**Flujo principal**
1. Se identifica un estudiante en la cola.
2. Se solicita o se ejecuta su retiro.
3. El sistema elimina al estudiante de la cola.
4. El sistema actualiza el estado de la cola.

**Flujos alternativos**
1. El estudiante no se encuentra en la cola → no se realiza acción.

**Postcondiciones**
1. El estudiante deja de formar parte de la cola.
2. La cola se actualiza correctamente.

**Excepciones**
1. Error al eliminar al estudiante.

## Módulo 3: Gestión de turnos

El módulo de gestión de turnos se encarga de asignar y controlar los turnos individuales de los estudiantes dentro del sistema. A partir de la información de la cola virtual, este módulo genera un turno con un horario específico para cada estudiante, respetando la disponibilidad y el orden previamente establecido.

Una vez asignado el turno, el módulo se encarga de gestionar su ciclo de vida, pasando por estados como pendiente, activo, confirmado o no confirmado. Esto permite tener un control claro sobre qué estudiantes harán uso del servicio y cuáles no.

Además, este módulo maneja la confirmación de asistencia, asegurándose de que el estudiante valide su turno dentro del tiempo establecido. En caso de que no lo haga, el sistema marca el turno como no confirmado y libera el cupo correspondiente.

Este módulo no se encarga de la organización de la cola ni de la reasignación de turnos, ya que esas funciones pertenecen a otros módulos del sistema. Su responsabilidad se centra únicamente en la gestión individual de cada turno, desde su creación hasta su finalización.

| ID   | Requisito Funcional                                                                                                        | Actor(es)  |
| ---- | -------------------------------------------------------------------------------------------------------------------------- | ---------- |
| RF07 | El sistema debe generar un turno para el estudiante a partir de su registro en la cola virtual.                            | Sistema    |
| RF08 | El sistema debe asignar al turno un horario específico dentro de un bloque de tiempo disponible.                           | Sistema    |
| RF09 | El sistema debe registrar cada turno con un identificador único.                                                           | Sistema    |
| RF10 | El sistema debe validar que el estudiante no tenga más de un turno activo antes de generar uno nuevo.                      | Sistema    |
| RF11 | El sistema debe cambiar el estado del turno a “activo” cuando se alcance su horario de inicio.                             | Sistema    |
| RF12 | El sistema debe permitir al estudiante confirmar su asistencia dentro del tiempo establecido.                              | Estudiante |
| RF13 | El sistema debe marcar el turno como “no confirmado” si el estudiante no realiza la confirmación dentro del tiempo límite. | Sistema    |
| RF14 | El sistema debe liberar el cupo asociado a un turno no confirmado.                                                         | Sistema    |
